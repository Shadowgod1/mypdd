# Jol Ustazy — тренажёр ПДД Республики Казахстан

«Жол ұстазы» — наставник дороги.

Бесплатная подготовка к теоретическому экзамену ПДД РК. Без рекламы, без регистрации,
без отправки данных куда-либо. Работает офлайн и ставится на телефон как приложение.

- **Виртуальный ассистент**: наводит на правило и показывает главу ПДД, но не называет ответ
- **251 вопрос** по 12 темам, у каждого — разбор с объяснением самого правила
- **Справочник рядом**: полный текст ПДД, 254 знака, разметка, штрафы, первая помощь
- **55 иллюстраций**: схемы перекрёстков, дорожные знаки, сигналы регулировщика — всё инлайн-SVG
- **Два языка**: русский и казахский (интерфейс переведён полностью, вопросы — постепенно)
- **Режим экзамена** совпадает с реальным форматом: 40 вопросов за 40 минут, порог 32
- Прогресс хранится в `localStorage` на устройстве

## Устройство репозитория

Документация: [ARCHITECTURE.md](ARCHITECTURE.md) — устройство, [STYLE.md](STYLE.md) —
оформление, [HANDOFF.md](HANDOFF.md) — состояние и задачи.

```
index.html          источник правды: разметка, стили и код одним файлом
tools/build.js      сборка сайта в docs/ (оборачивает index.html в полный документ)
tools/make-icons.js генератор иконок PWA, без внешних зависимостей
docs/               то, что раздаёт GitHub Pages (собирается, руками не правится)
```

Единый файл выбран сознательно: страницу можно сохранить и открыть без сервера и без сборки.

## Сборка

Нужен только Node.js.

```bash
node tools/make-icons.js docs   # иконки, достаточно один раз
node tools/build.js             # собрать сайт в docs/
```

Переименование приложения делается в одном месте — объект `CFG` в начале `tools/build.js`.

## Локальный запуск

Service worker требует `http://localhost` или HTTPS, с `file://` он не заработает.

```bash
python -m http.server 8137 --directory docs
```

## Публикация на GitHub Pages

В настройках репозитория: **Settings → Pages → Source: Deploy from a branch**,
ветка `main`, папка `/docs`.

Для своего домена добавьте файл `docs/CNAME` с одной строкой — именем домена,
и пропишите у регистратора DNS-записи на GitHub Pages. До покупки домена файл
создавать не нужно: он сломает адрес вида `*.github.io`.

## Как добавить перевод вопроса

Переводы лежат в объекте `KKQ` в `index.html` и привязаны к исходному русскому тексту
вопроса. Порядок вариантов обязан совпадать с русским массивом `o` — правильный ответ
хранится индексом, а не текстом.

```js
'Русский текст вопроса?':{
  q:'Сұрақтың қазақша мәтіні?',
  o:['...','...','...','...'],   // тот же порядок, что в русском
  e:'Түсіндірме.'
}
```

Если перевода нет, вопрос показывается по-русски — приложение остаётся рабочим.

## Проверки перед публикацией

```bash
node --check docs/sw.js
```

Осмысленно также прогнать базу вопросов: у каждого ровно 4 непустых варианта,
индекс правильного ответа в диапазоне, у казахских версий длина массива совпадает
с русской, все функции `img()` возвращают SVG.

## Оговорки о содержании

Вопросы авторские и составлены по действующим Правилам дорожного движения РК.
Это **не копия закрытой экзаменационной базы МВД РК**. Нормы сверены с текстом Правил,
опубликованным на [kazpdd.kz](https://kazpdd.kz/ru/rules); ещё один открытый
источник — [24pdd.kz](https://24pdd.kz/).

Отдельно: раздел первой помощи составлен по учебному материалу, который входит
в экзаменационную подготовку. Современные клинические рекомендации по сердечно-лёгочной
реанимации отличаются — 30 нажатий на 2 вдоха с частотой 100–120 в минуту. Об этом
сказано на странице «О проекте».

Перед экзаменом сверяйтесь с действующей редакцией Правил: скоростные режимы,
расстояния и перечень неисправностей меняются чаще остального.
