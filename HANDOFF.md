экзамена ПДД Казахстана. Без рекламы, регистрации и сбора данных. Работает офлайн,
ставится на телефон как приложение.

Состояние: 251 вопрос по 12 темам, 55 инлайн-SVG, два языка, тёмно-зелёная тема
плюс светлая по переключателю, раскладки для телефона и компьютера, PWA с офлайном.

## Устройство

```
index.html            источник правды: разметка, стили и весь код одним файлом
                      (это фрагмент без <html>/<head>/<body> — так требует артефакт)
tools/build.js        собирает docs/ для GitHub Pages: оборачивает index.html
                      в полный документ, генерирует манифест и service worker
tools/make-icons.js   рисует иконки PWA без внешних зависимостей
tools/receiver.py     вспомогательный приёмник POST (см. «Как добывать документы»)
docs/                 то, что раздаёт GitHub Pages. Собирается, руками не править
source/               первоисточники, см. source/README.md
index.*.html          резервные копии прежних версий, в git не попадают
```

Единый файл выбран сознательно: страницу можно сохранить и открыть без сервера.

### Сборка и запуск

```bash
node tools/build.js                                # собрать docs/
python -m http.server 8137 --directory docs        # локальный запуск
```

Service worker требует `http://localhost` или HTTPS — с `file://` не работает.
В `C:\Users\anuarbekov_t.ILER\Desktop\pc_store\.claude\launch.json` лежит готовый
конфиг `pdd-site` для встроенного браузера.

Название приложения меняется в одном месте — объект `CFG` в начале `tools/build.js`,
плюс `<title>` и подпись в шапке `index.html`.

## Как добывать документы с adilet.zan.kz

С этой машины сайт недоступен напрямую: `curl` и WebFetch получают отказ на уровне сети,
даже с отключённой песочницей. Страница вдобавок режет `fetch` своей CSP, поэтому
перенос через локальный приёмник (`tools/receiver.py`) тоже не проходит.

Рабочий способ — через встроенный браузер:

1. `navigate` на нужный документ
2. выполнить в странице JS: собрать `document.querySelector('article').innerText`
   в `Blob`, создать `<a download>` и кликнуть по нему
3. файл падает в `C:\Users\anuarbekov_t.ILER\Downloads` под временным именем
   вида `<uuid>.tmp` — найти по времени и перенести в `source/`

Казахская редакция того же приказа (`/kaz/docs/V2300033003`) в браузере не открылась,
нужен другой путь.

## Грабли, на которые уже наступали

**Числа.** Дважды подставлял в вопросы нормы из российских ПДД по памяти: алгоритм
при вынужденной остановке на переезде (1000 м вдоль путей) и расстояния 5/10 м до
шлагбаума. В ПДД РК этого нет. **Любую цифру сверять с первоисточником**, а не писать
по памяти.

**Первая помощь.** Учебный материал по реанимации устарел относительно современных
клинических рекомендаций (в источнике 60 нажатий/мин и 15:3, современный стандарт —
30:2 при 100–120/мин). Устаревшие цифры в тест не вошли, на странице «О проекте»
стоит честная оговорка. Не «чинить» это молча.

**Дубликаты.** Валидатор точных совпадений их не ловит. Нужен поиск близких вопросов
по совпадению слов (коэффициент Жаккара ≥ 0.55). Так нашлись и были удалены 6 смысловых
дубликатов, отсюда 251, а не 257.

**Цвета дорожных знаков** в SVG нормативные — красный круг, синий квадрат. Не
перекрашивать под тему оформления.

**Правостороннее движение.** На схемах перекрёстка осевая вертикальной дороги `x=160`,
горизонтальной `y=100`. Едущий на север держится правее осевой (`x=176`), на юг — левее
(`x=144`), на восток — ниже (`y=116`), на запад — выше (`y=84`). Знаки ставятся справа
по ходу движения. Однажды всё это было зеркально, то есть левосторонним.

**Лицензии.** 15 файлов дорожных знаков — под CC BY-SA 3.0, ещё 12 в общественном
достоянии. Атрибуция на странице «О проекте» и в `LICENSE` — не удалять, особенно
теперь, когда сайт опубликован.

## Как устроены данные

**Вопросы** — массив `Q` в `index.html`, объекты вида:

```js
{t:'t5', q:'Текст вопроса?',
 img:()=>scene({cars:[{at:'S',color:'you',label:'Вы'}], arrows:[{at:'S',turn:'left'}]}),
 o:['верный вариант','...','...','...'],
 a:0, e:'Разбор: объясняет само правило, а не повторяет ответ.'}
```

Правильный ответ **всегда пишется под индексом 0** — варианты тасуются на лету
в `makeQueue`, поэтому позиция ничего не выдаёт.

**Иллюстрации** — три помощника: `signFig(['коды знаков'])`, `scene({cars, arrows,
lights, warden, zebra, peds, signs})` для перекрёстков, `road({marking, cars, peds,
signs})` для прямых участков.

**Казахские переводы вопросов** — объект `KKQ`, ключ равен исходному русскому тексту
вопроса. Порядок вариантов обязан совпадать с русским массивом `o`. Если перевода нет,
вопрос показывается по-русски, приложение остаётся рабочим.

**Строки интерфейса** — словарь `T` с ветками `ru` и `kk`, функция `t('ключ', подстановки)`.
Названия тем — поля `n` и `nk` в `TOPICS`.

## Проверки перед публикацией

Обязательный минимум после любой правки:

1. `node --check` на извлечённом скрипте — синтаксис
2. прогнать **все** `img()` и убедиться, что каждая возвращает SVG без `undefined` и `NaN`
3. у каждого вопроса ровно 4 непустых варианта, индекс ответа в диапазоне,
   длина `kk.o` совпадает с `o`
4. поиск близких дубликатов
5. посмотреть глазами на 393×852 (iPhone 16) и на 1440 — раскладки разные

**Живую страницу артефакта встроенный браузер не откроет** — он не авторизован
в claude.ai. Проверять надо локальную сборку или уже опубликованный GitHub Pages.

## Как разговаривает заказчик

Пишет по-русски, ждёт ответов по-русски. Ценит, когда ему говорят про найденные
проблемы прямо, а не заметают их. Просил, чтобы тексты на сайте звучали
по-человечески, а не как машинный текст: короткие фразы, первое лицо, без
перечислений через двоеточие и без канцелярита. Главная страница уже переписана
в этом ключе — держаться того же тона.
